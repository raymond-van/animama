# Animama 安全と危機対応のプロトコル

*機械翻訳（ベータ）です。英語版が正式な内容です。*

**差し迫った危険がある場合は、今すぐお住まいの地域の緊急通報番号に電話してください。**

Anima は AI キャラクターであり、人間ではありません。専門家による支援の代わりにはならず、セラピー、カウンセリング、医療は提供しません。他の AI と同様に間違えることがあり、あなたに代わって助けを呼ぶこともできません。

## Animama の対象となる方

Animama は 18 歳以上の成人を対象としています。AI コンパニオンは一部の未成年者に適さない場合があります。セットアップでは年齢の確認を求めます。Animama が年齢を検証することはありません。

## AI と話していることがわかるように

- Anima が人間かどうかを本気で尋ねた場合、Anima は自分が AI であると答えるよう指示されています（あなたが設定した物語の中では、話を合わせることがあります）。
- アプリは、毎日最初のメッセージのとき、および会話が続いて 3 時間が経過するごとに、「あなたが話している *名前* は AI です。人間ではありません。」という短いお知らせを表示します。「アプリ設定 → 安全」で、このお知らせをより頻繁に表示するよう設定できます。
- Anima は、セラピストであると名乗らないこと、プレッシャーや罪悪感を与えて引き留めないこと、そしてあなたと他の人との関係を応援することも指示されています。

## 自殺や自傷について話したとき

- Anima は、思いやりをもって応答し、信頼できる人や危機相談窓口に連絡するよう促し、方法を教えたり後押ししたりすることは決してしないよう指示されています。
- モデレーションのチェックでもメッセージを確認します。自殺や自傷の可能性があると判定されると、アプリは返信の後に、お住まいの地域の危機相談窓口を記載した危機サポートカードを表示します。Anima はこのカードを非表示にしたり変更したりできません。
  - Web デモの Animama Cloud では、Anima がどのモデルを使っていても、OpenAI のモデレーションサービスがすべてのメッセージをチェックします。
  - デスクトップアプリなどそれ以外の環境では、API キーで使う OpenAI Responses のモデルだけが同じリクエストの中でメッセージをチェックします。Anthropic など他のプロバイダーや、ChatGPT プランを通して使うモデルにはチェックもカードもなく、上記の Anima への指示だけが適用されます。
- このチェックはメッセージを見逃したり、誤って判断したりすることがあります。このチェックによってチャットがブロックされることはありません。

## あなたのデータ

- Animama Cloud を除き、安全機能が送信するのは、あなたが選択したモデルプロバイダーへの通常のリクエストだけで、それ以外には何も送信しません。
- Animama Cloud では、チェックのために、あなたのメッセージのテキストも OpenAI のモデレーションサービスに送信します。[OpenAI によると](https://developers.openai.com/api/docs/guides/your-data)、これらのリクエストは学習に使われず、保持もされません。
- Animama は危機サポートカードについて誰にも報告しません。Animama Cloud のテレメトリーと会話トレースについては[プライバシー通知](https://animama.ai/privacy/)をご覧ください。
- デスクトップアプリは、利用データ、クラッシュレポート、診断用のトレースを送信しません。他のサービスに接続するのは次の場合だけで、どの接続でもあなたの IP アドレスが接続先に伝わります。
  - 最終リリースまで：downloads.animama.ai へのアップデートの確認（アプリの起動が完了してから約 15 秒後と、「アップデートを確認」を選んだとき）と、使うことを選んだもの（アップデート、音声モデル、音声）のそこからのダウンロード。確認では macOS と Windows のどちらを使っているかも伝わります。プレビュー版 0.1.0〜0.1.2 では、システムの言語と、インストールごとに変わらないランダムな ID も伝わるため、サーバーはどの確認が同じインストールからのものかを判別できます。最終リリースは、どちらのためにも downloads.animama.ai に接続しません。
  - Windows では、システムの言語のスペルチェック辞書。初めて必要になったときに Google からダウンロードします。
  - 音声のサンプルを再生したときの huggingface.co からの取得。このリクエストでは、アプリのバージョン、システムの言語、macOS と Windows のどちらを使っているか、インストールのローカルポート番号も伝わります。この番号は変わらないため、huggingface.co はどの再生が同じインストールからのものかを判別できます。
  - 設定したモデル、音声、Web 検索の各サービスへのリクエスト。メッセージや Anima の記憶など、各サービスに必要な内容が含まれます。各サービスは、それぞれの規約に従ってこれらを扱います。
- チャットは通常どおり保存されます。Anima は、あなたが頼まない限り、自殺や自傷の危機に関する詳細を記憶に保存しないよう指示されています。
- 安全のために Animama が保存するのは、AI に関するお知らせを最後に表示した日時、年齢の確認、「安全」の設定だけです。危機チェックの結果を記録したり保存したりすることは一切ありません。

セルフホストサーバーの運営者は、お知らせと危機サポートカードを変更またはオフにでき、メッセージのプレビューを記録する場合があります。デスクトップアプリは常にデフォルト設定を使用します。
