# Animama 安全与危机应对规程

*机器翻译（测试版）。以英文版本为准。*

**如果你正处于紧急危险中，请立即拨打当地的紧急求助电话。**

Anima 是 AI 角色，不是真人。它们不能替代专业帮助，也不提供心理治疗、心理咨询或医疗服务。和所有 AI 一样，它们可能会出错，也无法替你求助。

## Animama 的适用对象

Animama 供 18 岁及以上的成年人使用；AI 伙伴可能不适合部分未成年人。设置过程中会请你确认年龄。Animama 不会对此进行验证。

## 了解你在与 AI 交谈

- 如果你真心询问 Anima 是不是真人，它被要求说明自己是 AI（在你设定的故事情境中，它可能会配合剧情）。
- 应用会在你每天发送第一条消息时，以及连续对话每满 3 小时后，显示一条简短提示：“你正在与 *名字* 交谈，它是 AI，不是真人。”你可以在“应用设置 → 安全”中让提醒更频繁地出现。
- Anima 还被要求不得自称心理治疗师，不得通过施压或让你感到内疚来让你留下，并且要支持你与他人的关系。

## 如果你提到自杀或自我伤害

- Anima 被要求以关怀的态度回应，鼓励你联系你信任的人或危机热线，并且绝不提供方法或加以鼓动。
- 内容审核检查也会读取你的消息。如果检查标记出可能涉及自杀或自我伤害，应用会在回复之后显示一张危机支持卡片，列出你所在地区的危机热线。Anima 无法隐藏或更改这张卡片。
  - 在网页演示版 Animama Cloud 中，无论 Anima 使用哪个模型，OpenAI 的内容审核服务都会检查每一条消息。
  - 在包括桌面应用在内的其他环境中，只有通过 API 密钥使用的 OpenAI Responses 模型会在同一请求中检查消息。Anthropic 等其他提供商以及通过 ChatGPT 套餐使用的模型既没有检查，也没有卡片，只有上面对 Anima 的指示适用。
- 这项检查可能会漏判或误判消息。聊天绝不会因为这项检查而被阻止。

## 你的数据

- 除 Animama Cloud 外，安全功能只会向你所选的模型提供商发送常规请求，不会发送任何其他内容。
- 在 Animama Cloud 中，我还会把你每条消息的文字发送给 OpenAI 的内容审核服务以进行检查。[OpenAI 表示](https://developers.openai.com/api/docs/guides/your-data)不会用这些请求进行训练，也不会保留它们。
- Animama 不会向任何人报告危机支持卡片。Animama Cloud 的遥测和对话追踪记录见其[隐私声明](https://animama.ai/privacy/)。
- 桌面应用不会发送使用数据、崩溃报告或诊断追踪记录。它只在以下情况下连接其他服务，每次连接都会让对方得知你的 IP 地址：
  - 在最终版本之前：在应用启动完成约 15 秒后以及你选择“检查更新”时，向 downloads.animama.ai 检查更新，并从那里下载你选择使用的内容：更新、语音模型或语音。检查还会表明你使用的是 macOS 还是 Windows。在预览版 0.1.0 至 0.1.2 中，检查还会表明你的系统语言以及每个安装固定不变的随机 ID，因此服务器可以判断哪些检查来自同一个安装。最终版本不会为这两者连接 downloads.animama.ai。
  - 在 Windows 上，首次需要时从 Google 下载你的系统语言的拼写检查词典。
  - 播放语音样本时，从 huggingface.co 获取该样本。此请求还会表明应用的版本、你的系统语言、你使用的是 macOS 还是 Windows，以及你的安装所用的本地端口号。该端口号不会改变，因此 huggingface.co 可以判断哪些播放来自同一个安装。
  - 向你设置的模型、语音和网页搜索服务发送请求，其中包含各服务所需的内容，例如你的消息和 Anima 的记忆。各服务依照其自身条款处理这些内容。
- 聊天会照常保存。Anima 被要求不要将自杀或自我伤害危机的细节保存到记忆中，除非你要求它这样做。
- 出于安全目的，Animama 只存储 AI 提示上次显示的时间、你的年龄确认以及你的安全设置。它从不记录或存储危机检查的结果。

自托管服务器的运营方可以更改或关闭该提示和危机支持卡片，并且可能会记录消息预览。桌面应用始终使用默认设置。
